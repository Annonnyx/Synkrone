Créer un bot

Preparer son Bot sur le Portail Discord

Suivez ces etapes dans l'ordre pour configurer correctement votre bot sur Discord.

1Obtenir le Token

Rendez-vous sur le Discord Developer Portal et creez une nouvelle application.

Dans le menu Bot cliquez sur Reset Token. Copiez cette cle secrete dans un endroit sur et ne la partagez sous aucun pretexte.

2Activer les Intents

Les intents autorisent le bot a lire les messages et analyser les membres du serveur.

Descendez vers Privileged Gateway Intents. Cochez imperativement Presence, Server Members et Message Content puis sauvegardez.

3Inviter le Bot

Generez le lien d'invitation pour joindre votre bot a un serveur Discord.

Allez dans OAuth2 puis URL Generator. Cochez les cases bot et applications.commands. Donnez-lui la permission Administrator et ouvrez le lien genere.

import discord
from discord.ext import commands
import os
from dotenv import load_dotenv

load_dotenv()

class MonBot(commands.Bot):
    def __init__(self):
        super().__init__(command_prefix="!", intents=discord.Intents.all())

    async def setup_hook(self):
        for filename in os.listdir('./cogs'):
            if filename.endswith('.py'):
                await self.load_extension(f'cogs.{filename[:-3]}')
        await self.tree.sync()

    async def on_ready(self):
        print(f'Connecte en tant que {self.user}')

bot = MonBot()
bot.run(os.getenv("TOKEN"))

import discord
from discord.ext import commands

class PingCog(commands.Cog):
    def __init__(self, bot):
        self.bot = bot

    @commands.hybrid_command(name="ping", description="Affiche la latence du bot")
    async def ping(self, ctx):
        latency = round(self.bot.latency * 1000)
        await ctx.send(f'Pong ! Latence : {latency}ms')

async def setup(bot):
    await bot.add_cog(PingCog(bot))

import discord
from discord.ext import commands

class ClearCog(commands.Cog):
    def __init__(self, bot):
        self.bot = bot

    @commands.hybrid_command(name="clear", description="Supprime un nombre precis de messages")
    @commands.has_permissions(manage_messages=True)
    async def clear(self, ctx, nombre: int):
        if nombre < 1 or nombre > 100:
            return await ctx.send("Veuillez choisir un nombre entre 1 et 100.", ephemeral=True)

        # Si commande textuelle on ajoute 1 pour effacer la commande elle-meme
        limit = nombre if ctx.interaction else nombre + 1

        await ctx.defer(ephemeral=True)
        deleted = await ctx.channel.purge(limit=limit)
        await ctx.send(f"{len(deleted)} messages supprimes !", ephemeral=True, delete_after=3)

async def setup(bot):
    await bot.add_cog(ClearCog(bot))

import discord
from discord.ext import commands

class BanCog(commands.Cog):
    def __init__(self, bot):
        self.bot = bot

    @commands.hybrid_command(name="ban", description="Bannir un membre du serveur")
    @commands.has_permissions(ban_members=True)
    async def ban(self, ctx, membre: discord.Member, *, raison: str = "Aucune raison specifiee"):
        await membre.ban(reason=raison)
        await ctx.send(f"{membre.name} a ete banni. Raison : {raison}")

async def setup(bot):
    await bot.add_cog(BanCog(bot))

require('dotenv').config();
const { Client, Collection, REST, Routes } = require('discord.js');
const fs = require('fs');

const client = new Client({ intents: 3276799 });
client.commands = new Collection();

const commandFiles = fs.readdirSync('./commands').filter(file => file.endsWith('.js'));
const commandsData = [];

for (const file of commandFiles) {
    const command = require(`./commands/${file}`);
    client.commands.set(command.name, command);
    commandsData.push({ name: command.name, description: command.description, options: command.options || [] });
}

client.once('ready', async () => {
    const rest = new REST({ version: '10' }).setToken(process.env.TOKEN);
    await rest.put(Routes.applicationCommands(process.env.CLIENT_ID), { body: commandsData });
    console.log(`Connecte en tant que ${client.user.tag}`);
});

client.login(process.env.TOKEN);

module.exports = {
    name: 'ping',
    description: 'Affiche la latence du bot.',
    async execute(context) {
        const start = Date.now();
        const reply = await context.reply({ content: 'Calcul en cours...', fetchReply: true });
        const end = Date.now();

        const latency = end - start;
        const text = `Pong ! Latence : ${latency}ms`;

        if (context.editReply) {
            await context.editReply(text);
        } else {
            await reply.edit(text);
        }
    }
};

    async execute(context, args) {
        let targetUser;
        if (context.commandName) {
            targetUser = context.options.getUser('membre') || context.user;
        } else {
            targetUser = context.mentions.users.first() || context.author;
        }

        const embed = new EmbedBuilder()
            .setTitle(`Profil de ${targetUser.username}`)
            .setThumbnail(targetUser.displayAvatarURL())
            .addFields(
                { name: 'ID', value: targetUser.id },
                { name: 'Creation', value: new Date(targetUser.createdTimestamp).toLocaleDateString('fr-FR') }
            );

        await context.reply({ embeds: [embed] });
    }

Commande Clear▼ 
const { PermissionsBitField } = require('discord.js');

module.exports = {
    name: 'clear',
    description: 'Nettoyer le salon.',
    options: [{ name: 'nombre', type: 4, description: 'Nombre de messages', required: true }],
    async execute(context, args) {
        if (!context.member.permissions.has(PermissionsBitField.Flags.ManageMessages)) {
            return context.reply({ content: 'Permissions insuffisantes.', ephemeral: true });
        }

        let amount = context.commandName ? context.options.getInteger('nombre') : parseInt(args[0]);
        if (!context.commandName) amount++;

        if (amount > 100 || amount < 1) return context.reply('Nombre invalide.');

        await context.channel.bulkDelete(amount, true);

        const msg = await context.channel.send(`Messages supprimes.`);
        setTimeout(() => msg.delete(), 3000);
    }
};
Commande Ban▼ 
const { PermissionsBitField } = require('discord.js');

module.exports = {
    name: 'ban',
    description: 'Bannir un utilisateur.',
    options: [{ name: 'membre', type: 6, description: 'Membre a bannir', required: true }],
    async execute(context, args) {
        if (!context.member.permissions.has(PermissionsBitField.Flags.BanMembers)) {
            return context.reply({ content: 'Permissions insuffisantes.', ephemeral: true });
        }

        const target = context.commandName
            ? context.options.getUser('membre')
            : context.mentions.users.first();

        if (!target) return context.reply('Membre introuvable.');

        await context.guild.members.ban(target.id, { reason: 'Banni via commande' });
        await context.reply(` ${target.username} a ete banni definitivement.`);
    }
};

Logiciel

Checklist utile pour garder un bot propre, stable et maintenable, avec les infos IDE que tu utilisais avant.

Visual Studio Code Le standard

L'editeur le plus stable pour coder des bots. Ecosysteme massif d'extensions, terminal integre efficace et controle complet du projet.

  • Tres bonne stabilite pour les gros projets.
  • Personnalisation complete (themes, raccourcis, snippets).
  • Ideal pour garder un controle manuel sur chaque fichier.

Cursor Le rapide

Base sur VS Code, avec une experience acceleree pour l'ecriture et la navigation. Pratique quand tu enchaines les iterations rapidement.

  • Interface familiere si tu viens de VS Code.
  • Autocompletion et generation plus agressives.
  • Ideal pour reduire les taches repetitives.

Windsurf Le contextuel

Oriente comprehension globale du codebase. Adapté aux projets modules avec beaucoup de fichiers et dependances croisées.

  • Bonne lecture du contexte projet global.
  • Flux de travail pratique pour refactoriser.
  • Ideal pour les architectures lourdes.
