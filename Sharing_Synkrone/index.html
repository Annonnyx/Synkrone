1. Configuration du Fichier .env

Configure les identifiants et le token de ton bot directement dans le fichier .env situé à la racine du dossier du bot.

DISCORD_TOKEN=votre_token_secret_ici PREFIX=!

2. Installation des Dépendances & Lancement

Ouvre un terminal dans le répertoire du bot et installe les paquets requis (en pensant bien à aiohttp et python-dotenv) :

pip install -r requirements.txt pip install aiohttp python-dotenv

Lance ensuite ton script principal :

python main.py
